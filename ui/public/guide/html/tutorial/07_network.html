네트워크 구성 및 관리

namuVIRT는 VM 및 VM의 네트워크를 관리의 편의성을 위해 다양한 종류의 가상 네트워크와 그 네트워크의 설정을 지원한다. 각 네트워크의 설정은 크게 연결성과 L2의존도가 큰 L2/Shared Network, 각 네트워크 간의 고립을 강조하는 Isolated Network, VPC 및 내부 서브넷을 통해 트래픽 분산 또는 접근 제한을 제공하는 VPC Network가 있다.

L2/Shared Network

Virtual Network 개념 없이 바로 L2와 VM을 연결하고 싶거나 최소한의 DHCP 기능이 필요하다면 L2 Network나 Shared Network를 이용하면 된다.

아래 L2 네트워크 예시는 L2 Bridge에 VM을 직접 연결하는 L2 Network의 예시이다. 이 네트워크의 IP 범위, Gateway등의 설정은 전부 L2네트워크가 기준이 된다.

단순한 구조는 namuVIRT의 관리 포인트가 줄어든다는 장점이 있지만 L2 설정에 종속되어 이후 네트워크의 구성 변경이 힘들다.

Shared Network는 L2 Network와 유사하지만 DHCP/DNS 기능을 Virtual Router를 통해 제공받는 차이점이 있다. 단순히 L2가 DHCP를 제공해 주길 기다리는 것과는 반대로 Virtual Router의 DHCP와 DNS를 통해서 IP를 제공받는다. 아래의 Shared Network 예시는 VM들이 L2에 직접 연결되지 않고 Virtual Router에 연결된다는 것이 묘사된다.

Shared Network를 생성할 때는 L2 및 외부망이 어떤 상태인가를 고려하면서 설정해야 외부망/네트워크와 일치된 설정이 가능하다. Shared Network는 내부 IP와 Public IP라는 개념이 존재하지 않기 때문에 잘못된 설정을 적용하면 L2 및 외부망과 불일치하면서 Virtual Network 자체가 동작하지 않게 된다.

Isolated Network

Isolated Network는 Shared Network와 외부에 영향을 받지 않는 독립적인 네트워크 영역을 생성한다. 이 네트워크에 속한 VM들은 서로와 통신할 수 있지만, 반대로 다른 Shared/Isolated Network의 VM과는 통신할 수 없다. 또한, 외부망에 연결되기위해서 Source NAT를 가지게 된다. 아래 Isolated Network 예시는 Isolated Network가 Shared Network와는 달리 Private IP를 가지고 외부와 격리되는 것을 보여준다.
